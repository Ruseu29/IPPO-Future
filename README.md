# IPPO Future

日本語入力の打ち間違いを自動で直す、**Windows 64bit向けの試用アプリ**です。まだ直せない誤字や、意図しない修正もあります。

## 使い方

1. ZIPを右クリックして **「すべて展開」**。
2. 展開した **`IPPO Future` フォルダ**を、今後も使う場所に置く。
3. フォルダ内の **`デスクトップにショートカットを作る.bat`** をダブルクリック。
4. デスクトップにできた **`IPPO Future (EXE)`** から起動。
5. 起動後は**自動修正が始まり、一度だけ最小化**します。通知領域のアイコンをクリックすると画面を開けます。

**停止は `F8`、終了は `×`。** 起動時は毎回、自動修正で開始します。「観察のみ」は動作タブで選べます。`exe` だけを移動せず、フォルダ全体を保管してください。

## 状態の見方
※通知領域のアイコンも変化します。

| 表示 | 意味 |
| --- | --- |
| **動作中** | 入力を監視し、条件に合えば自動修正します。 |
| **観察のみ** | 判定はしますが、文字は修正しません。 |
| **停止中（修正停止）** | 監視・修正を止めています。「開始」で再開します。 |
| **送信中断（待機中）** | 修正が間に合わなかった等のエラーで一時待機。入力の区切りなどで再開します。 |
| **拒否済み・中断** | 拒否登録した修正だけ見送り、監視は続けます。 |
| **エラー** | 安全のため停止中。画面のエラー内容を確認してください。 |

## 困ったとき

### 修正されない、されすぎる

環境設定の **「修正パワー調整」** を開き、プリセットを選んでください。

- **弱（初期値）**：修正を控えめにします。
- **中**：弱より修正の候補を通しやすくします。
- **強**：さらに修正しやすくします。誤修正にも注意してください。

変更後は項目の下の **「修正パワーを保存」** を押すと次回へ引き継ぎます。有効な未保存変更があるときだけ青色で押せます。プリセットの選択では動作モードや開始／停止状態は変わりません。

画面は800×480から広げられます。収まらない内容はタブ内をスクロールしてください。分析には「入力のようす（live）」「おためし入力」「ログ」があります。

### 誤修正した

**`Ctrl + Alt + R`** で、直前に実行された修正を**次回から拒否**できます。文字を元に戻す操作ではありません。拒否の取り消しは **「拒否一覧・解除」** から。

### 起動できない

フォルダを移動した場合は、**移動先のショートカット作成BATをもう一度実行**してください。古いショートカットは削除します。フォルダ内の `IPPO Future.exe` からも起動できます。

### 停止・削除

入力がおかしくなったら **`F8` または「停止」**。止まらなければタスクマネージャーから `IPPO Future` を終了してください。

使わなくなったらアプリのフォルダとデスクトップのショートカットを削除します。**設定・修正履歴・拒否登録も消す**場合は、エクスプローラーで `%LOCALAPPDATA%\IPPO Future` を開き、そのフォルダも削除してください。

### 入力は保存される？

**「タイプログの保存」は初期ON**です。起動後、自動修正とともに対象の入力の記録も始まります。保存済みのON/OFFは引き継ぎます。不要なら環境設定でOFFにしてください。タイプログと通知の変更は自動保存されます。

記録はEXEの横の `学習ログ` フォルダへJSONLで保存し、分析の「タイプログを開く」から確認できます。物理打鍵・IMEの状態・入力の区切り・自動修正の開始と結果を区別して残します。アプリからの自動送信・再学習はありません。機密入力時は保存OFFまたはF8で停止してください。Drive等の同期対象に置くとログにもその同期設定が適用されます。

### Macでは使える？

現在はWindows専用です。Mac対応も早めに進めたい一方、開発者自身がMacで常用できないため、将来的に実機での試用協力が必要です。
