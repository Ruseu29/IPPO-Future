# IPPO Future

日本語入力の打ち間違いを自動で直す、**Windows 64bit向けの試用アプリ**です。まだ直せない誤字や、意図しない修正もあります。

## ダウンロード

**[Windows版をダウンロード（ZIP）](https://github.com/Ruseu29/IPPO-Future/releases/download/v0.1.0-preview.2/IPPOFuture_0.1.0-preview.2_windows-x64.zip)**  
`0.1.0-preview.2` ／ Pythonのインストール不要

## 使い方

1. ZIPを右クリックして **「すべて展開」**。
2. 展開した **`IPPO Future` フォルダ**を、今後も使う場所に置く。
3. フォルダ内の **`デスクトップにショートカットを作る.bat`** をダブルクリック。
4. デスクトップにできた **`IPPO Future (EXE)`** から起動。
5. 「学習用の入力を保存」を確認し、**「開始」**を押す。

**停止は `F8`、終了は `×`。** アプリは最初、停止した状態です。`exe` だけを移動せず、フォルダ全体を保管してください。

## 状態の見方
※タスクバーのアイコンも変化します。
| 表示 | 意味 |
| --- | --- |
| **動作中** | 入力を監視し、条件に合えば自動修正します。 |
| **観察のみ** | 判定はしますが、文字は修正しません。 |
| **停止中（修正停止）** | 監視・修正を止めています。「開始」で再開します。 |
| **送信中断（待機中）** | 修正が間に合わなかった等のエラーで一時待機。放置で自動再開します。 |
| **拒否済み・中断** | 拒否登録した修正だけ見送り、監視は続けます。 |
| **エラー** | 安全のため停止中。画面のエラー内容を確認してください。 |

## 困ったとき

### 修正されない、されすぎる

修正されない／されすぎる場合は、画面の **「しきい値」→③「修正候補の点数・下限」** を調整してください。

- **6：積極的**（誤修正にも注意）
- **10：中間**
- **14：慎重**（初期値）

変更後は **「設定を保存」**を押してください。

### 誤修正した

**`Ctrl + Alt + R`** で、直前に実行された修正を**次回から拒否**できます。文字を元に戻す操作ではありません。拒否の取り消しは **「拒否一覧・解除」** から。

### 起動できない

フォルダを移動した場合は、**移動先のショートカット作成BATをもう一度実行**してください。古いショートカットは削除します。フォルダ内の `IPPO Future.exe` からも起動できます。

### 停止・削除

入力がおかしくなったら **`F8` または「停止」**。止まらなければタスクマネージャーから `IPPO Future` を終了してください。

使わなくなったらアプリのフォルダとデスクトップのショートカットを削除します。**設定・修正履歴・拒否登録も消す**場合は、エクスプローラーで `%LOCALAPPDATA%\IPPO Future` を開き、そのフォルダも削除してください。

### 入力は保存される？

**「学習用の入力を保存」は初期ON**です。後の学習に使う予定ですが、現状不要です。「開始」前にOFFにしてください。記録はアプリの `学習ログ` フォルダに保存され、アプリから自動送信・再学習はされません。OneDriveなどの同期対象に置く場合はご注意ください。

### Macでは使える？

現在はWindows専用です。Mac対応も早めに進めたい一方、開発者自身がMacで常用できないため、将来的に実機での試用協力が必要です。
