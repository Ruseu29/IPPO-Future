# IPPO Future

Windows向けの日本語入力補助アプリです。入力ミスの修正を手助けします。

## ダウンロード

**[Windows 64bit版をダウンロード（ZIP）](https://github.com/Ruseu29/IPPO-Future/releases/download/v0.1.0-preview.2/IPPOFuture_0.1.0-preview.2_windows-x64.zip)**

確認版：0.1.0-preview.2 · Pythonのインストールは不要です。

## 使い方

1. ZIPを右クリックし、「すべて展開」します。
2. 展開したフォルダの「IPPO Future.exe」を開きます。
3. 入力保存の設定を確認して「開始」を押します。F8で停止、×で終了します。

EXEと「_internal」は同じフォルダに置いてください。
デスクトップに置く場合は、同梱の「デスクトップにショートカットを作る.bat」を実行します。
旧版が動いている場合は、先に停止してください。

## 入力の保存について

**この配布版は「学習用の入力を保存」が初期ONです。**
「開始」後の対象となる日本語入力を、EXEの横の「学習ログ」フォルダに保存します。
不要な場合は、開始前にチェックを外してください。ON/OFFは自動で記憶します。
既に使ったことがあるPCでは、保存済みの設定を優先します。

保存した入力の自動学習・アプリからの外部送信はありません。
機密情報を入力するときは保存をOFFにするか、F8で停止してください。
Drive等の同期フォルダに置く場合、ログにもその同期設定が適用されます。

設定・修正履歴の保存先：`%LOCALAPPDATA%\IPPO Future`

詳しい操作はZIP内の「利用方法.txt」をご覧ください。
